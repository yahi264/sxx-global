# SXX Global — sourcing, expediting & inspection (website proposal)

A redesign proposal for an industrial sourcing, expediting and inspection company: a static single-page site in English, Turkish, German, French and Arabic (RTL), with an interactive order journey, an NDT methods explorer, a 4-step quote builder and a rule-based assistant.

All identifying details (name, phone, email) are placeholders.

Built by Yahia Ait Ou Hmade, freelance web developer.
